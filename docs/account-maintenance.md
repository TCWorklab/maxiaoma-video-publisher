# 三平台账号登录维护

适用：马小马视频发布平台的抖音、小红书、微信视频号。此功能不保证永久在线，不会绕过扫码、验证码或平台验证。

## 使用

1. 按照 [部署说明](DEPLOYMENT.md) 启动，打开 `http://localhost:5173/#/account-management`。
2. 在「账号登录维护」启用后台定时维护，保存间隔。建议先用 60 分钟，允许 15–1440 分钟；每个账号还能单独暂停。
3. 查看最近检测、最近成功和明确状态。点击「检测」执行一次只读检查；点击「重新扫码 / 人工验证」打开现有登录入口。关闭前端登录对话框不会关闭平台窗口，取消时请关闭平台窗口；最长等待 10 分钟。
4. 任务因账号状态或账号忙而暂停时，原发布参数保存在本地库，并出现在「待处理发布任务」。先处理账号，再点击**恢复发布**。扫码成功本身不会自动发布。
5. 「结果不明确」表示已进入平台发布代码但没有明确成功，或者服务在执行期间中断。必须在平台创作者中心人工核对；系统不会恢复这类任务，也会拦住相同未决参数的新调用。不要通过新建相同任务绕过核对。

新安装默认关闭定时维护，正常间隔默认 60 分钟。关闭定时维护只停止定时访问；发布执行前的安全检查仍然生效。

系统设置中的「发布前检测 / 启动时检测」表示额外检测的时机，与定时维护独立。三平台在真正进入发布代码前，仍须持有账号锁且有最近 5 分钟内的可靠有效证据；已确认失效、人工验证、缺失或检测异常的账号不会进入新发布。

## 状态与会话保存

| 状态 | 判断与行为 |
| --- | --- |
| 登录有效 | 在平台 HTTPS 创作者页面，连续两次看到平台特定的账号身份及后台数据区域，且没有登录或安全验证提示。保存更新后的会话。 |
| 已失效 | 连续看到明确登录提示，且不具有已登录账号身份或处在登录页。要求扫码，停止自动重试。 |
| 需要人工验证 | 明确可见安全验证、滑块、风险或频率限制提示。停止自动重试，交由用户处理。 |
| 登录文件缺失 | 没有该账号的本地会话，要求扫码。 |
| 检测异常 | 超时、网络、HTTP 错误、页面结构不匹配、证据不足或文件保存失败。保留旧凭据、历史成功时间和旧账号 `status`，不将其直接标为失效。 |

检查不依赖「HTTP 200」「没有重定向」「没有找到登录按钮」证明有效。页面适配规则在 `backend/services/session_probe.py`；平台改版可能导致保守的「检测异常」，需复核并维护选择器。检测异常按 5、10、20 分钟等指数退避，最多 24 小时；人工点击检测可以明确发起复查。

会话只由已验证的维护、扫码或导入流程写入。先在会话同目录建立临时文件，写入并 `fsync`，再 `os.replace`；失败保留原文件。发布流程不再直接覆盖会话。Cookie 和 localStorage 不进入状态 API、维护日志或发布任务记录。导入失败不替换已有会话；重新导入保留已有账号的文件名，避免待处理任务引用失效。

## 并发、停止与恢复

- 按规范化后的账号会话路径使用操作系统文件锁。普通视频、批量、草稿、图集、MCP 队列、扫码、导入、同步、创作中心和定时维护共用该锁；删除、修改账号和上传会话也会避让。
- 维护浏览器同时最多 1 个，扫码同时最多 1 个，三平台发布同时最多 1 个。不同账号允许在不同操作类别下使用；忙账号的维护会跳过。
- Windows 使用 `msvcrt`，macOS/Linux 使用 `fcntl`。进程退出释放锁；锁文件留在数据目录不会造成永久锁死。
- 原视频号每 30 分钟的独立线程已移除。新调度器有停止事件、启动防重和跨进程主调度锁。关闭服务时应先停止维护调度器，再结束本项目进程；保存的开关不会因停止而丢失。macOS 使用现有启动方法并通过正常进程关闭结束服务。
- 新增 `account_maintenance` 和 `guarded_publications` 两张表，不改变已有账号表结构或删除数据。任务记录保存发布参数引用；视频和封面文件仍须保留。
- 恢复使用原任务 ID 和数据库条件更新，重复点击不会再次进入发布。调用前持久化 `running`；执行中崩溃按 `unknown` 恢复。只有从未进入平台代码的 `waiting` 任务可恢复或取消。
- 远端平台与本地数据库没有分布式事务，因此不能承诺远端恰好一次发布。多文件或多账号调用中途失败会将整个调用保守标为结果不明确，不重跑可能已经成功的部分。
- 服务重启前尚未执行的普通视频任务会转为待处理；暂停任务与结果不明确记录跨重启保存。历史记录沿用原发布明细 ID。

## 实现入口与接口

- `services/session_store.py`：状态存储、账号路径限制、跨进程锁、原子会话替换。
- `services/session_probe.py`：三平台只读页面证据与会话更新。
- `services/account_maintenance.py`：统一调度与平台入口保护。`BasePlatform.__init_subclass__` 仅为 1/2/3 三平台安装包装，直接实例化同样生效。
- `services/publication_guard.py`：持久任务、进入发布前检查、幂等恢复和模糊结果隔离。
- `blueprints/maintenance_bp.py`：状态与配置 API；`AccountMaintenancePanel.vue`：账号管理入口。

| API | 用途 |
| --- | --- |
| `GET /api/account-maintenance` | 账号状态、时间、配置和待处理任务；不返回会话或任务原始载荷 |
| `POST /api/account-maintenance/config` | `{ "enabled": true, "intervalMinutes": 60 }` |
| `POST /api/account-maintenance/<id>` | `{ "enabled": false }` 单账号暂停 |
| `GET /checkAccount?id=<id>` | 人工只读检查，保留 `valid/status` 兼容字段并增加 `state` |
| `POST /api/account-maintenance/jobs/<id>/resume` | 只恢复尚未进入发布代码的任务 |
| `POST /api/account-maintenance/jobs/<id>/cancel` | 只取消尚未提交的任务 |
| `POST /api/account-maintenance/stop` | 停止调度器，不修改保存的启停设置 |

实现依据：[Playwright storage_state](https://playwright.dev/python/docs/api/class-browsercontext#browser-context-storage-state)、[Python os.replace](https://docs.python.org/3/library/os.html#os.replace)。平台识别采用本仓库已有页面结构，真实平台覆盖范围以下面的实测为准。

## 验证范围

维护功能包含模拟测试和本地页面验证；这不代表三平台长期登录或真实发布已全部验收。
平台要求扫码、验证码或人工验证时，仍需账号持有人操作。

运行模拟测试时，请将 `SAU_DATA_DIR` 指向新的测试目录；不要使用正式账号的数据目录。
在 backend 目录安装 pytest 后执行：`python -m unittest tests.test_account_maintenance -v`。
